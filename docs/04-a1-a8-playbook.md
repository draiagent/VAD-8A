# 04｜A1–A8 Playbook

## A1 Agent Formation

**目的**：明確誰看、誰想、誰做、誰驗證、誰批准。

輸出：Agent Role Map

驗收：所有關鍵步驟都有 Owner、權限與交接點。

## A2 Visual Problem Definition

**目的**：把「感覺有問題」轉成可量化問題。

輸出：VAD Problem Card

驗收：5W2H、KPI、成本、問題邊界、證據來源完整。

## A3 Containment Execution

**目的**：降低問題擴散，不把暫時措施誤認為永久改善。

輸出：Containment VAC

驗收：Containment Efficiency、受影響範圍、解除條件明確。

## A4 Root Cause Reasoning

**目的**：找系統原因，不找戰犯。

輸出：Root Cause Map

驗收：每個 Why 有證據；Root Cause 是已驗證的可測試假說。

## A5 Corrective Action Design

**目的**：選擇可持續的永久改善方案。

輸出：Action VAC

驗收：至少比較成本、時間、風險、效果與 Owner。

## A6 Verify

**目的**：用數據證明改善有效。

輸出：Verify Report

驗收：Before / After、時間窗、KPI、判定門檻明確。

## A7 Prevention & Automation

**目的**：把有效做法安裝到企業系統中。

輸出：Reusable Capability

驗收：SOP / Rule / Skill / Workflow / Monitoring 至少一項完成並可被觸發。

## A8 Learn & Reuse

**目的**：將成功與失敗都變成知識資產。

輸出：Enterprise Memory

驗收：Lessons Learned、版本、適用範圍、下次觸發條件完整。

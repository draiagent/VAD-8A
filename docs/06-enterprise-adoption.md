# 06｜Enterprise Adoption

## 導入順序

### Phase 1：選一個高頻、低風險問題
不要一開始就自動化重大事故處理。

### Phase 2：先做 VAD
先把現有流程、角色、資料來源與例外畫清楚。

### Phase 3：建立 VAC
把成功做法轉成結構化能力卡。

### Phase 4：Agent 執行
從資料抓取、報表整理、提醒與建議開始。

### Phase 5：Verify
建立 Before / After 與可稽核 KPI。

### Phase 6：Reuse
把 verified VAC 納入企業能力庫。

## 建議 PoC 成功條件

- 處理時間下降 ≥ 30%
- 人工核對時間下降 ≥ 50%
- Verify Pass Rate ≥ 95%
- 無重大權限或安全事件
- 至少 1 個 VAC 被第二次成功重用

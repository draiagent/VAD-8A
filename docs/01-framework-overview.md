# 01｜Framework Overview

## VAD-8A 八階段

### A1 Agent Formation
建立 Human Owner、Orchestrator Agent、專業 Agent 與權責地圖。

### A2 Visual Problem Definition
以 VAD Problem Card 將 5W2H、KPI、成本、影響、資料來源與問題邊界視覺化。

### A3 Containment Execution
利用既有規則快速止血，依風險決定 Agent 自動執行、通知或 Human Approval。

### A4 Root Cause Reasoning
建立 Root Cause Hypothesis；使用 5 Why、Fishbone、歷史案例與數據證據形成可追蹤推理鏈。

### A5 Corrective Action Design
提出多方案並比較成本、時間、風險、影響與可持續性。

### A6 Verify
以前後 KPI、控制組、時間窗或統計方法驗證改善是否有效。

### A7 Prevention & Automation
把已驗證方案轉成 SOP、Rule、Skill、Workflow、Alert、Monitoring。

### A8 Learn & Reuse
整理 Lessons Learned、版本化 VAC、存入企業能力庫，在下一次相似事件直接調用。
